# Noticias · Mr. Supply Chain®

Sección de noticias de https://mrsupplychain.ai/noticias/ — briefs de mercados (apertura, mediodía y cierre de Wall Street, global y México) leídos desde supply chain y operaciones, en español e inglés.

- `index.html`, `news.css`, `news.js`: la página (JS y CSS externos por la CSP del sitio).
- `data/latest.json`: el brief más reciente, mercados y lectura.
- `data/index.json`: lista de briefs publicados.
- `data/briefs/<id>.json`: cada brief.

Hostinger despliega la rama `main` en `public_html/noticias`. Los datos los actualizan tareas programadas de Claude en días hábiles. No guardes aquí contraseñas ni llaves: el repo es público.
